# CodeAlpha - C++ Projects

Welcome to my **CodeAlpha C++ Projects Repository** 🚀

This repository contains a collection of beginner-friendly **C++ console applications** developed as part of my programming practice and CodeAlpha internship tasks.

The projects focus on programming fundamentals, problem-solving, input handling, functions, data structures, recursion, and basic algorithms.

---

## 📌 Projects

### 1. 🧮 CGPA Calculator

A console-based application that calculates **Semester GPA and Overall CGPA** using a 4.0 grading scale.

#### Features
- Enter multiple semesters
- Enter multiple courses
- Add course name
- Enter letter grades
- Enter credit hours
- Calculate Semester GPA
- Calculate Overall CGPA
- Display detailed semester results
- Input validation

#### Concepts Used
- C++ Structures
- Vectors
- Functions
- Loops
- Conditional Statements
- Input Validation
- Mathematical Calculations
- Formatted Output

#### Concepts Used

### 3. 🧩 Sudoku Solver

A **9×9 Sudoku Solver** that solves Sudoku puzzles using the **Backtracking Algorithm**.

#### Features
- Enter your own Sudoku puzzle
- Use a sample Sudoku puzzle
- Validate the input puzzle
- Check rows and columns
- Check 3×3 sub-grids
- Automatically solve the puzzle
- Detect puzzles with no solution
- Display the solved Sudoku

#### Concepts Used
- 2D Arrays
- Functions
- Recursion
- Backtracking
- Loops
- Conditional Statements
- Input Validation
- Algorithmic Problem Solving
